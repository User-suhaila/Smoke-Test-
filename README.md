# Survey Module Automation

End-to-end automation framework for the survey creation and submission workflow on [https://stg-genforms.mobilityeye.com/](https://stg-genforms.mobilityeye.com/), built with Playwright + JavaScript following the Page Object Model pattern.

---

## Prerequisites

- **Node.js** v18 or later
- **Playwright** `@playwright/test` ^1.61.1 (installed via `npm install`)

---

## Installation

1. **Clone the repository** and navigate to the project root.

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Install the Chromium browser binary:**
   ```bash
   npx playwright install chromium
   ```

---

## Environment Setup

The framework reads credentials and configuration from a `.env` file in the project root.

1. Copy the example file:
   ```bash
   cp .env.example .env
   ```

2. Open `.env` and fill in your values:
   ```
   BASE_URL=https://stg-genforms.mobilityeye.com/
   USERNAME=your-email@example.com
   PASSWORD=your-password-here
   HEADLESS=true
   ```

See `.env.example` for the full list of supported variables. The `.env` file is excluded from source control — never commit real credentials.

## Running Tests

### Headless (CI / default)

Runs the full test suite without a visible browser window:

```bash
npm test
```

### Headed (local debugging)

Runs the tests with the browser window visible:

```bash
npm run test:headed
```

### View HTML Report

Opens the Playwright HTML report generated by the last test run:

```bash
npm run test:report
```
